# Security and privacy

## Prototype status

This repository contains a local product prototype. It does not include a production backend, authentication, a database, analytics, or persistent student profiles. The AI companion is scripted for demo reliability.

Do not use the prototype to collect or process real information about minors.

## Before production use

A production version should include, at minimum:

- Verifiable age-appropriate student and parent/guardian consent
- Parent controls with clear, revocable permissions
- Data minimization and documented retention/deletion policies
- Encryption in transit and at rest
- Role-based access control and secure session handling
- Moderation and abuse-reporting workflows
- Safe AI output policies, monitoring, and escalation paths
- Independent security, privacy, and legal review
- A process for responding to incidents and data-subject requests

## Reporting issues

Please report a security concern privately to the repository owner. Do not include personal information, credentials, or real student data in a public GitHub issue.
